Политика конфиденциальности

Последнее обновление: 2026-08-12

Stah — это инструмент для управления собственной VPN-инфраструктурой пользователя. Это приложение НЕ предоставляет VPN-сервис и НЕ имеет доступа к вашему интернет-трафику.

Что собирает приложение

Приложение генерирует уникальный идентификатор устройства (device key) — случайный UUID. Этот идентификатор используется для привязки лицензии к установке и передаётся на ваш собственный сервер при настройке. Никакие личные данные (имя, email, контакты, местоположение) не собираются.

Где хранятся данные

Все данные (IP-адрес сервера, пароли, конфигурации) хранятся локально на вашем устройстве и на вашем собственном сервере. Разработчик приложения не имеет доступа к вашим серверам, паролям или трафику. Приложение не передаёт ваши данные третьим лицам.

Платёжная информация

При оплате через криптовалюту (USDT) приложение отправляет хэш транзакции на ваш собственный сервер для проверки. Разработчик получает уведомление об активации лицензии (идентификатор устройства, IP вашего сервера, временная метка) — это необходимо для подтверждения оказания услуги. Платёжные данные кошелька разработчиком не обрабатываются.

Уведомления

При активации платной лицензии ваш сервер отправляет разработчику уведомление через Telegram-бота. Это необходимо для подтверждения факта активации и разрешения спорных ситуаций. Уведомление содержит: идентификатор устройства, IP-адрес сервера и временную метку.

Разрешение камеры

Камера может использоваться для сканирования QR-кодов при настройке (если эта функция добавлена). Фото и видео не сохраняются и не передаются.

Доступность сервера разработчика

Приложение работает автономно после настройки. Связь с серверами разработчика происходит только при проверке лицензии и активации покупки. Отсутствие связи не блокирует использование уже настроенного VPN.

Изменения политики

Политика может быть обновлена в новых версиях приложения. Продолжение использования приложения после обновления означает согласие с новой редакцией.
